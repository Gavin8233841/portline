# 七号货运场地图数据

`yard-07.json` 来自正式试玩版的关卡导出。世界单位按米，`x` 向东，`z` 向南，`y` 是高度，地面 `y = 0`。

| 字段 | 格式 |
| --- | --- |
| `spawns` | `{ x, y, z, side, yaw, home?, entrance? }`；`side` 为队伍，`yaw` 为弧度。 |
| `boxes` | `[x0, y0, z0, x1, y1, z1, flags, pane]`；轴对齐包围盒。`flags & 1` 不挡移动，`flags & 2` 不参与射线命中；`pane` 为玻璃索引，`-1` 表示没有。 |
| `glassCount` | 玻璃索引数量。 |
| `nav` | `[x, y, z, links]`；`links` 是从零起算的导航节点索引，按有向边读取。 |

地图查看器按高度绘制截面，所见轮廓是碰撞盒，不是可见模型的网格。跨层边在「全部」层显示。
